# 중고차 적정가 — QM6 · SM6 LPG (MVP)

엔카 실매물 스냅샷(2026-11-21)을 기반으로 연식·주행·트림 조건의 적정가 범위를 계산하는 정적 웹사이트입니다.

## 기능
- 조건 입력: 차종(QM6/SM6) · 연식 · 주행거리 · 트림 · 옵션(정보용)
- 실시간 계산: 중앙값, P25~P75 범위, 신뢰도(표본 수), 신차 대비 잔존율
- 매물 가격 입력 시 **급매 / 적정 / 비쌈** 판정
- 같은 조건 매물 가격 분포 히스토그램
- 조건을 URL 쿼리로 저장 (`?m=QM6&y=2021&km=70000&t=RE&p=1620`)
- 모바일 하단 고정 요약 바

## 실행
```bat
start.bat
```
또는
```bash
python -m http.server 8123
# 브라우저에서 http://127.0.0.1:8123
```
`file://`로 직접 열면 JSON fetch가 차단되므로 반드시 로컬 서버로 실행하세요.

## 구조
```
car-price-mvp/

  data/meta.json       # 출처·주의사항
  scripts/build_data.py
  start.bat
```

## 데이터
- 원천: 엔카 실매물 LPG(일반인 구입) 스냅샷 2026-11-21, 중복 제거
  - QM6 LPG 436대, SM6 LPG 231대
- 통계: 연식별 중앙값/P25/P75/P10/P90, 중앙 주행거리, 가격 분포 10구간, 트림별 통계(n≥5)
- 주행 보정: 모델별 회귀 기울기 (QM6 -44.1만/1만km, SM6 -30.5만/1만km), 보정 상한 ±15%
- 옵션: 300대 표본 장착률만 표시. **가격 가산 없음** (300대 분석에서 양의 프리미엄 미확인)

## 데이터 갱신
1. 엔카 스냅샷을 `scripts/build_data.py`의 `ENCAR_SRC` 경로에 준비
2. `python scripts/build_data.py`
3. `data/*.json` 갱신 후 커밋

## 한계
- 등록 호가 기준 (실계약은 3~10% 낮을 수 있음)
- 표본 10대 미만 연식은 참고용
- 사고·렌터카 이력 미통제
- 엔카 링크는 메인 페이지로 연결 (모델 검색 딥링크는 추후 개선)
- 옵션 코드 001~008은 의미 충돌로 이름 표시 제외
