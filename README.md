# 중고차 적정가 — 르노코리아 (MVP)

엔카 실매물 스냅샷(2026-11-21)을 기반으로 모델·연료·연식·주행·트림 조건의 적정가 범위를 계산하는 정적 웹사이트입니다.

## 지원 모델 (14개)
QM6 · SM6 · XM3 · SM3 · SM5 · SM7 · QM3 · 아르카나 · 마스터 · QM5 · 클리오 · 트위지 · 캡처 · 조에

## 기능
- 조건 입력: 모델 · 연료 · 연식 · 주행거리 · 트림 · 옵션(정보용)
- **렌터카·사고 이력 제외 토글** (기본 ON): 렌터카 · 전손 · 침수 · 도난 · 500만원 이상 사고 매물 제외
- 실시간 계산: 중앙값, P25~P75 범위, 신뢰도(표본 수), 신차 대비 잔존율(QM6/SM6 LPG)
- 매물 가격 입력 시 **급매 / 적정 / 비쌈** 판정
- 같은 조건 매물 가격 분포 히스토그램
- 조건을 URL 쿼리로 저장 (`?m=QM6&f=lpg&y=2021&km=70000`)
- 모바일 하단 고정 요약 바

## 실행
```bat
start.bat
```
또는
```bash
python -m http.server 8123
# 브라우저에서 http://127.0.0.1:8123
```
`file://`로 직접 열면 JSON fetch가 차단되므로 반드시 로컬 서버로 실행하세요.

```
car-price-mvp/

```

## 데이터
- 원천: 엔카 실매물 스냅샷 2026-11-21, 중복 제거
  - 14개 모델 · 총 4,418대 (LPG · 가솔린 · 디젤 · 하이브리드 · 전기)
  - QM6: LPG 436 · 가솔린 451 · 디젤 298 / SM6: 가솔린 612 · LPG 231 · 디젤 53
- 통계: 모델·연료·연식별 중앙값/P25/P75/P10/P90, 중앙 주행거리, 가격 분포 10구간, 트림별 통계(n≥5)
- **전체(all) / 정제(clean) 두 가지 통계** 제공. clean은 렌터카·전손·침수·도난·500만원 이상 사고 제외
- 차량이력: 엔카 record API(사고·전손·침수·도난·소유자변경·렌터카 용도) 수집 (`scripts/collect_flags.py`)
- 주행 보정: 모델·연료별 회귀 기울기, 보정 상한 ±15%
- 옵션: 모델별 표본(6~150대) 장착률만 표시. **가격 가산 없음** (300대 분석에서 양의 프리미엄 미확인)

## 데이터 갱신
1. 엔카 스냅샷을 `scripts/build_data.py`의 `ENCAR_SRC` 경로에 준비
2. `python scripts/build_data.py`
3. `data/*.json` 갱신 후 커밋

## 한계
- 등록 호가 기준 (실계약은 3~10% 낮을 수 있음)
- 표본 10대 미만 연식은 참고용
- 모델·연료별 표본 차이가 큼 (예: ZOE 14대, 아르카나 63~37대)
- 사고·렌터카 이력 미통제
- 엔카 링크는 메인 페이지로 연결 (모델 검색 딥링크는 추후 개선)
- 옵션 코드 001~008은 의미 충돌로 이름 표시 제외
